## Projeto em Python sobre A ideia SMART SAVE para a empresa da JOVI.

• O Smart Save é uma função da câmera que realiza a análise automática da cena em tempo real ao abrir o aplicativo. Utilizando recursos de visão computacional, o sistema identifica elementos como textos e rostos para sugerir, de forma inteligente, a melhor categoria de salvamento, como “Estudos” ou “Pessoal”.
Essa sugestão aparece diretamente na interface da câmera, de maneira discreta, permitindo que o usuário aceite ou altere com apenas um toque, sem interromper o fluxo de uso. Após a captura, a imagem é automaticamente organizada na categoria escolhida.
Com isso, o Smart Save reduz o esforço do usuário, otimiza o tempo, ajuda na organização e oferece uma experiência mais prática e eficiente, especialmente para o público estudante.

### Código

• Menu de opções implementadas ao sistema de acordo com necessidades do usuário através da câmera e software do Smart Save.

• Organização do sistema em subrotinas (funções).

• Utilização adequada de parâmetros e retorno de funções.

• Validações em entrada de usuário.

• Manipulação de dados utilizando dicionários.

• Aplicação de boas práticas de programação.

• Interface intuitiva, com mensagens claras e fácil navegabilidade.
